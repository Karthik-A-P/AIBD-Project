  Each model's importance is normalized to sum to 1. The cells collect them in
  one importances table, then plot the top 20 genes per model.

  - Logistic Regression: the absolute coefficient. The features are
    standardized, so the coefficients are comparable.
  - Random Forest: feature_importances_.
  - SVM: the RBF kernel has no coefficients, so I used permutation importance on
    the test set. This is the mean absolute change in the SVM's decision
    function when a gene is shuffled across test samples.
  - SVM speed: sklearn's permutation_importance would have taken hours on 12,720
    genes (about 0.67 s per prediction, roughly 38,000 predictions). I compute
    the same quantity directly from the RBF kernel formula instead. I checked
    one gene against sklearn's decision_function and the two values matched to
    about 10 digits.
  - Accuracy as the metric: I used the decision-function change rather than
    accuracy drop because the test set has only 37 samples. That makes accuracy
    drops mostly zero.

  lr_model = evaluate(...), svm_model = ... and rf_model = ....
